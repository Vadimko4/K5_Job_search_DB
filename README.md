# Проект "K5_Job_search_DB"

## Описание:

Проект является курсовой работой к пятому модулю обучающего курса Skypro "Профессия Python-разработчик".
Продолжает тему прошлой курсовой, посвящён получению и анализу вакансий с сервиса HH.ru. 
Но он дополнен работой с базами данных postgreSQL - это основная тема данной курсовой работы. 
В проекте, кроме функционального, так же используется объектно ориентированное программирование. 


## Логика работы программы: 

1. Из файла config.py программа получает список id работодателей, вакансии которых будут ей отслеживаться.
2. С сайта hh.ru получаем общую информацию об этих работодателях - название компаний и количество открытых вакансий.
3. Оттуда же получаем определённое количество актуальных вакансий. Их число задаётся константой API_VACANCY_PER_PAGE.
4. По полученной информации создаём базу данных из двух первичных таблиц. Таблица о работодателях и о вакансиях.
5. В программу введена третья таблица - текущая таблица вакансий. Она содержит отфильтрованные по поиску вакансии.
6. Далее используется интерфейс пользователя. Он реализован основной функцией, обслуживающей основное меню пользователя.

Меню содержит следующие команды:

1. Вывести список компаний с указанием количества вакансий в текущей таблице
2. Вывести список всех вакансий в текущей таблице
3. Получить среднюю зарплату по вакансиям текущей таблицы
4. Вывести список вакансий, у которых зарплата выше средней по вакансиям текущей таблицы
5. Отфильтровать и вывести вакансии, в названии которых содержится ключевое слово
6. Сбросить фильтры на вакансии в текущей таблице
7. Выход из программы

## Описание модулей:

### main
«Точка входа» — модуль, запустив который, можно получить результат всех реализованных в проекте функциональностей.

### utils

В данном модуле реализованы все вспомогательные функции, необходимые для работы интерфейса 
пользователя. В частности моменты вывода текста меню на экран консоли, ввода данных пользователем через консоль. 
Ввод обслуживает специальная функция. В ней реализована "защита от дурака". Здесь же представлены 2 сервисных
функции для работы по созданию и заполнению базы данных полученной информацией.

### config

Модуль содержит список отслеживаемых работодателей, а так же считывает необходимую для подключения к postgreSQL 
информацию. Она содержится в файле database.ini
При развертывании проекта, вам необходимо будет указать Ваши данные - согласно файлу шаблона database.ini.example

### db_manager

Работает с информацией БД. Реализован как класс, объекты которого умеют всё, что предусматривает основное меню 
пользователя. Первичная информация о работодателях и вакансиях с сайта hh.ru содержится непосредственно в экземпляре
объекта. Более широкие возможности (в частности фильтрацию по словам в названии вакансий) даёт третья, 
дополнительно созданная таблица БД - таблица текущих вакансий. 

У вакансий в таблицах выделены 5 основных атрибутов:
- название работодателя
- название вакансии
- зарплата от
- зарплата до
- уникальная ссылка на вакансию, дабы пользователь имел возможность перейти по ней и посмотреть подробности

В классе реализованы все основные методы, необходимые для работы кода.

### hh_handler

Для получения данных с сайта www.hh.ru так же написан класс, который использует API ресурса. 
Код может "выжимать" всё возможное из бесплатного варианта работы с ресурсом - получать до 2000 вакансий 
от одного работодателя. 

Здесь две основные функции. Одна получает информацию о работодателях. Вторая - об их вакансиях.
Для данного приложения на www.hh.ru зарегистрирован access token. Однако, оно успешно работает и без него 
(строка 36 закоментирована). Если захотите использовать токен, раскомментируйте строку 36 и закоментируйте строку 37.
Если будут возникать проблемы с api - раскоментируйте строки 118-120 в самом конце модуля. Они добавляют паузы между 
запросами.

## Установка:

1. Клонируйте репозиторий:
```
git clonegit@github.com:Vadimko4/K5_Job_search_DB.git
```
или
```
git clone https://github.com/Vadimko4/K5_Job_search_DB.git
```

2. Установите зависимости:
```
poetry install
```
3. Ознакомьтесь с инструкцией в файле database.ini.example и донастройте окружение (введите свои данные для БД)

## Использование:

Запустите на выполнение файл main.py
